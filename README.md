# SEL 成語心情冒險

適合 2～4 位國小中低年級學生進行的 SEL 情緒與成語網頁遊戲。

遊戲包含三個關卡：

1. **情緒偵探**：從生活情境中辨識並排列情緒。
2. **情緒大富翁**：擲骰前進，運用成語、生活情境與感官線索描述情緒。
3. **成語情境挑戰**：將情緒成語運用在生活情境中，完成任務並累積心情點數。

## 使用方式

直接開啟 `index.html`，或使用本儲存庫的 GitHub Pages 網址，即可在手機、平板或電腦上遊玩。

## 教學提醒

- 建議由教師先示範一輪，再讓學生分組進行。
- 遊戲中的情緒沒有好壞之分，重點是練習辨識、理解與適切表達。
- 情境討論應尊重學生是否願意分享個人經驗。
